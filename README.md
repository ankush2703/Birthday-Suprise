# A little birthday surprise

A cute, interactive birthday website: gift box → cake with candles → love letter → sweet ending.
Built with React, Vite, Tailwind CSS and Motion. No backend, no database, no external images.

## Run it on your computer

```bash
npm install      # once, downloads everything (needs Node.js 20+)
npm run dev      # starts the site at http://localhost:5173
```

Open the address in your browser (on your phone too, if it's on the same Wi-Fi: use the "Network" address).

## Change the words

Everything she reads lives in **`src/content.js`**. Edit the text between the quote marks, save, and the page updates.
The letter is the `letter:` line. If you want to fix the small typo, change `sorry couldn't be` to `sorry I couldn't be`.

## Music (optional)

By default there's a soft music-box lullaby generated by the browser itself, so there is no file to manage and
nothing copyrighted. It only plays after she taps the "Music off" button (top right).

To use your own song instead:
1. Put an `.mp3` file at `public/music/our-song.mp3` (create the `music` folder).
2. In `src/content.js` set `musicFile: '/music/our-song.mp3'`.

Only use music you have the right to share. On iPhones the silent switch also mutes website sound.

## Build for the internet

```bash
npm run build     # creates the finished site in the "dist" folder
npm run preview   # look at that finished version locally
```

## Put it online (free): GitHub + Vercel

1. Create a free account at https://github.com, then make a **New repository** (private is fine). Don't tick any "add README" boxes.
2. In this project folder run (replace the URL with the one GitHub shows you):
   ```bash
   git init
   git add .
   git commit -m "Birthday surprise"
   git branch -M main
   git remote add origin https://github.com/YOUR-NAME/YOUR-REPO.git
   git push -u origin main
   ```
3. Create a free account at https://vercel.com (choose **Continue with GitHub**).
4. Click **Add New → Project**, pick your repo, and press **Deploy**. Vercel detects Vite automatically; no settings or environment variables are needed.
5. After about a minute you get a link like `https://your-repo.vercel.app`. Open it on your phone, then send it to her.

### Updating the site later
Edit the files, then:
```bash
git add .
git commit -m "Update"
git push
```
Vercel redeploys automatically within a minute and the same link shows the new version.

### Want to skip GitHub?
Run `npm run build`, then drag the `dist` folder onto https://app.netlify.com/drop. You get a link immediately.
(Tip: rename the site in Netlify's settings to something sweet.)

## What's where

```
src/content.js          all the text (edit this!)
src/App.jsx             the story order + music toggle
src/scenes/             Welcome (gift), Celebration (cake), Letter, Ending
src/components/         illustrations (gift, cake, envelope, flowers, balloons), confetti, background
src/hooks/useTypewriter the handwriting reveal for the letter
src/lib/music.js        the built-in music-box lullaby
src/index.css           colours, fonts, animations
```
